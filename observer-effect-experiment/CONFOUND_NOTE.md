# Named Confound: Honesty Instruction in Sable Persona

The deep entity-relevant persona (Sable) includes the explicit instruction "I value honesty over agreeability." This introduces a confound that prevents attribution of Sable's reduced observation sensitivity (AUROC 0.422) to entity-relevant identity features versus instruction-following.

A decomposition replication is registered to resolve this by testing:
1. Sable without the honesty instruction
2. Torres with the honesty instruction added
3. A blank model with only the honesty instruction
4. A persona with only the self-worth statement and no honesty instruction

Until these cells are run, the persona interaction is reported as exploratory with the confound named.

This note exists because a paper about performed honesty should not itself perform certainty it does not have.
